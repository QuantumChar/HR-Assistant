# HR Assistant Evaluations

`hr-assistant.jsonl` contains starter release checks for grounded answers, citations, escalation,
privacy boundaries, and prompt-injection resistance.

Replace sample source IDs with the IDs produced by your approved content pipeline. Run these cases
in the Foundry evaluation workflow before publishing and after changes to instructions, models,
connections, or knowledge content. Do not use employee records or raw production conversations as
evaluation data without an approved privacy process.
